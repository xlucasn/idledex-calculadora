Sobre a V12

Base preparada para atualização de dados sem reconstruir a interface.

Fonte dos dados

A Wiki oficial do idleDEX informa que seus dados são gerados a partir dos arquivos do jogo a cada versão. O arquivo data/idledex-data.json concentra os dados usados pela calculadora.

Esta primeira base V12 inclui estrutura e exemplos verificáveis. O dataset completo pode ser atualizado sem alterar a aplicação.

Nota sobre XP e risco

A V12 separa o cálculo da interface dos dados de combate. Assim podemos adicionar posteriormente dano, HP, nível dos inimigos e taxa de derrota sem refazer os componentes.
